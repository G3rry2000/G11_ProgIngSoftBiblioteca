Detailed Description

Interfaccia per la gestione della persistenza dei dati.

Definisce le operazioni fondamentali per leggere e scrivere i dati di un archivio su file. Le classi che implementano questa interfaccia devono fornire un meccanismo concreto di persistenza.

void biblioteca.Archivio.leggiDaFile ( String filename) throws IOException

Carica i dati dell'archivio da un file di testo.

Legge il contenuto del file indicato e popola la struttura dati dell’archivio. L’implementazione deve definire il formato dei dati.

Parameters
filenamePercorso del file da cui leggere i dati.
Exceptions
IOExceptionSe si verifica un errore di I/O durante la lettura.
Precondition
filename != null && !filename.isEmpty()
Postcondition
I dati dell’archivio sono aggiornati con le informazioni contenute nel file.

void biblioteca.Archivio.scriviSuFile ( String filename) throws IOException

Salva i dati dell'archivio su un file di testo.

Scrive sul file specificato lo stato corrente dell’archivio. L’implementazione deve garantire che il formato sia coerente con quello utilizzato per la lettura.

Parameters

Exceptions

Precondition

Postcondition
