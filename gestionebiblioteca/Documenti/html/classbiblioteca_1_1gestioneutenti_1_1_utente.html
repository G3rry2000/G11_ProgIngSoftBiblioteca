Detailed Description

Rappresenta un utente del sistema bibliotecario.

Questa classe contiene i dati dell'utente e le operazioni per gestire la lista dei prestiti attivi. Tutti i controlli sono stati affidati alla classe {

◆ getPrestitiDataRest()

String biblioteca.gestioneutenti.Utente.getPrestitiDataRest ( )
inline

Restituisce le date di fine dei prestiti attivi.

Se non ci sono prestiti attivi, restituisce la stringa "Nessuna". Altrimenti, concatena le date formattate come "dd/MM/yyyy", separate da una virgola e uno spazio.

Returns
Una stringa contenente le date di fine dei prestiti attivi, oppure "Nessuna" se la lista è vuota o nulla.

Restituisce i titoli dei libri presenti nei prestiti attivi.
