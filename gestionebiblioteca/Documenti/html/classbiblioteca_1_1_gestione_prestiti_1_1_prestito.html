Detailed Description

Rappresenta un prestito del sistema bibliotecario.

Questa classe contiene solo i dati del prestito Tutti i controlli sono stati affidati alla classe PrestitoService

void biblioteca.GestionePrestiti.Prestito.setContatore ( int val)
inlinestatic

Imposta il valore del contatore degli ID Questo metodo viene utilizzato dopo aver caricato da file l'ultimo ID assegnato, così che il contatore interno non riparta da 0 ma continui correttamente dalla posizione salvata.

Parameters
vall'ultimo ID letto da file (nuovo valore del contatore)
Precondition
val deve essere un intero >= 0 e rappresentare un ID valido già presente nei dati caricati.
Postcondition
Il contatore interno della classe avrà valore pari a val.
