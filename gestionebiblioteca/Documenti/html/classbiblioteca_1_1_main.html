Detailed Description

Classe principale dell'applicazione Biblioteca.

Estende Application e rappresenta il punto di avvio dell'applicazione JavaFX. Si occupa di caricare la scena iniziale dalla vista FXML HomeView.fxml e di mostrare la finestra principale.

L'applicazione utilizza FXMLLoader per caricare la GUI e Stage per visualizzare la finestra principale.

void biblioteca.Main.start ( Stage primaryStage) throws IOException

Inizializza e mostra l'interfaccia grafica principale.

Metodo richiamato automaticamente dal framework JavaFX all'avvio dell'applicazione. Inizializza gli archivi a partire dai file CSV, carica la vista principale tramite HomeView.fxml, crea la scena associata e visualizza la finestra principale.
